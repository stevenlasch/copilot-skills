# 4MAT Framework Copilot Skill

## About the 4MAT Framework
I recently discovered something called the 4MAT Framework that explains complex topics into Why, What, How and Now! 

### Here are each of those in detail.

1. WHY. The purpose. Start with why it matters. Why should your audience care? Why is this importan right now? If they don't buy into the "why", nothing else matters.
2. WHAT. The Big Picture. Give them the 10,000-foot view. Break it into 3-4 key pillars so they can see the full landscape.
3. HOW. The Process. Now show how it actually works. This is where you connect ideas to real world application. Make it tangible and make it relevant.
4. NOW. The Action. Finally, tell them what to do next. What's the one clear action they can do that moves the needle.

## Copilot CLI Users

1. The skill should be stored at `\~/.copilot/skills/4mat-framework/SKILL.md`
2. Once install, restart copilot and use the following commands:
 - /skills list — confirm it's loaded
 - /skills reload — reload after edits

### Trigger it with:

- Use the /4mat-framework skill to explain \[topic]
- 4MAT this: \[topic]
- Explain \[topic] using the 4MAT framework

## GitHub Copilot for the Web users

Create .github/skills/4mat-framework/SKILL.md in any GitHub repo, paste in the skill content, and it'll be available when working in that repo on github.com/copilot.
